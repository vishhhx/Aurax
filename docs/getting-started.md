# Getting Started

> **Superseded (2026-10-26).** This page describes an earlier design and is kept for history.
> The current, code-verified contract is [frontend-environment.md](frontend-integration/frontend-environment.md#local-stack).

## Prerequisites

- Node.js 18+
- Bun
- Docker (optional, for local services)

## Install Dependencies

```bash
bun install
```

## Run Services

```bash
bun run dev
```

## Environment Variables

Set the required environment variables for the gateway, auth service, wallet service, and websocket service before starting the stack.
